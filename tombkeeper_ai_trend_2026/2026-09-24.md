## 二、各领域商业化进展扫描（今日增量）

### 1. 客户服务 ⭐ 最接近的候选（估值与收入双确认）
- **Sierra**：估值 $15.8B（2026-05 融资 $950M）；ARR 轨迹 $100M（2025-11）→ $150M（2026-02）→ 目标 $500M（2026 年底）；Fortune 50 中 40%+ 为客户。
- **全球 AI 客服市场 2026 ~$15.1B**（Salesforce State of Service 系）；其中 AI 语音 agent $6.8B（+62% YoY，Gartner）。
- 采用率：66% 客服组织已用 agent（2025 为 39%，Salesforce）；70% 部署者 60 天内见可测价值。
- 同类估值梯队：Decagon $4.5B（客服）、Parloa $3B、Ada ~$1B、Cresta ~$1B、PolyAI $750M——客服是 agent 估值最集中的非编程垂直。
- **风险**：Sierra ~100x P/S，估值驱动 > 利润驱动；Agentforce 高增长引发"agent 侵蚀席位"定价悖论（Salesforce 股价年内 -33%）。
- **判断**：agent 原生收入池 $4–8B，在**上移后的一半线（$7.5–10B）下略低于线**；按旧口径则已触线。收入真实、增速惊人、单位经济可算，纯玩家盈利未验证。

### 2. 企业办公 / 通用 Agent 工作流
- **M365 Copilot 付费席位 3,000 万+**（单季 +50%），按 $30/席/月估算年化 **~$10B 量级**（昨日已报，维持）。
- **Gartner（2026 口径）**：2026 年底 40% 企业应用将内嵌任务级 agent（2025 <5%）；agentic AI 占企业应用软件收入 2%（2025）→ 30% / **$450B（2035）**——长期空间确认，但主要兑现在 2027 之后。
- 企业 agent 大盘 2026 **$11.55B**（Precedence，2025 为 $7.92B）；2030 各机构预测收敛于 $50–53B（MarketsandMarkets $52.62B / fwdslash $50–53B，罕见一致）。
- 落地现实：62% 企业实验中、仅 23% 规模化（McKinsey）；88% 企业 agent 项目未进生产（IDC/Lenovo）；Gartner 警告 2027 年底前 40%+ agentic 项目或被取消。
- **判断**：办公 Agent 年化 ~$10B ≈ **修正后一半线，规模达标**；盈利记在微软整体账上（FY2026 Q4 营收 $90B），独立平台多数在投入期。

### 3. AI Agent / 自动化（通用平台口径）
- 中国市场：企业级 Agent 2026 ~449 亿元（+112%）；AI 智能体整体 2026 ~1,558 亿元（沙利文/头豹）——TAM 口径为主，实际收入沉淀在平台巨头（阿里云 AI 相关收入破千亿、千问 C 端 MAU 3 亿）。
- 垂直 agent：35% 专注细分痛点的项目已正向现金流，客单价为通用 SaaS 的 3–5 倍（腾讯云，2026-06）。
- **判断**：长尾在赚钱、平台在烧钱；通用平台口径（$11.55B）贴修正后一半线，但含客服+办公重叠。

### 4. 内容创作 / 营销
- 可灵年化 ~$500M（+300%）、Midjourney ~$500M（已盈利）、Runway $300M。
- 反面：Sora 2026-04 关停（推理成本 $15M/日 vs 累计收入 $2.1M）。
- **判断**：头部合计 $1.5–2B，有盈利案例，规模距线远。

### 5. 法律 / 合规
- Harvey 以 **$14–15.5B 估值融资 $1.2B**；Legora $10–12B 估值融资 $866M；EvenUp $2.0–2.3B；Spellbook $1.2–1.8B。

### 6. 医疗 / 健康

- **判断**：规模口径边缘、盈利口径不满足。维持。

### 7. 金融 / 分析、教育、游戏

- 教育：AI tutors $2.75B（2026），Duolingo 盈利但盘子远不够。

### 8. 自动驾驶 / Robotaxi（观察项）

## 四、判断结论

**双口径框架，因编程基准上望而微调：**

1. **严格按用户基准（一半 = $25–50B 实际收入）：❌ 尚未出现。**
   非编程场景无一达到 $25B 年收入。最大三个收入池：办公 Agent（~$10B，计入微软整体盈利）、客服 agent（$4–8B，头部未盈利）、企业 agent 整体（$11.55B，含前两者重叠）。距 $25B 门槛仍有 2.5 倍以上差距，2026 年内（剩 3 个月余）翻转概率 **<15%**。

2. **按 AI 编程实际收入口径（一半 = $7.5–10B，今日上移）：⚠️ 边缘，达标项更少。**
   - **办公 Agent（Copilot 生态）年化 ~$10B**：**恰好压线**，且微软整体盈利——若认定"办公 Agent"为独立场景，宽松口径下条件满足。
   - **客服 Agent 收入池 $4–8B**：旧口径（$5–6.5B）触线，**新口径下略低于线**；Sierra 百倍 P/S 提示"赚钱"仍待验证。
   - **通用企业 agent 平台 $11.55B**：含客服+办公重叠，不宜重复计为独立场景。
   - 同时满足"非烧钱 + 规模"的独立纯玩家：**仍无**。

**一句话判断**：截至 2026-09-24，严格口径答案仍为"**尚未出现**"，且本月编程侧（Claude Code 三个月翻 3 倍至 $8B ARR）使一半线整体上移，非编程场景相对**更远**而非更近。当前唯一规模达标项是嵌入微软/Salesforce 账本的办公/客服 Agent（在位渠道变现），独立 AI 原生公司中无盈利的规模玩家。年内严格口径翻转概率 <15%；首个真正候选的时间窗指向 **2027–2028**（客服/agent 收入池按 45%+ CAGR 届时触 $25B）。
