# AI市场机会追踪：tombkeeper问题

**追踪日期**: 2026-06-06
**追踪问题**: 除了编程，2026年底前会出现另一个能赚钱（非烧钱）且市场规模至少是编程一半的大模型业务场景吗？
**编程市场基准**: $50-100B（一半是 $25-50B）

---

## 一、最新AI领域进展（过去24小时）

1. **Anthropic秘密提交IPO申请**：估值$9650亿，AI行业史上最大规模IPO之一。核心产品Claude系列企业市场表现强劲，网络安全AI产品Mythos引发全球关注。亚马逊持股从$80亿飙升至$740亿。

2. **英伟达发布Cosmos3**：全球首款全开源、全模态物理AI大模型，能处理文本、图像、视频、3D点云和物理传感器数据。联合多家行业巨头成立「宇宙联盟」，推动物理AI标准化和产业化。

3. **GitHub Copilot推出按使用量计费新定价**：放弃固定月费，按代码补全次数、AI对话轮次和Token量计费。重度用户月费用从$10飙升至数百美元，反映AI编程工具规模化后的成本压力。

4. **Anthropic递归自我改进研究报告**：2026年Q2工程师平均每天合并代码量是2024年的8倍，超过80%的合并代码由Claude编写。Claude Opus 4.6已能处理12小时级别的任务。

5. **NVIDIA推出Vera ARM架构AI超级芯片**：进军$2000亿CPU市场，专为AI Agent PC场景设计。微软、戴尔、惠普为首批合作伙伴。

6. **MiniMax发布M3大模型**：编程能力超越GPT-5.5，三大核心能力开源。

## 二、各潜在大模型业务场景分析

### 1. AI Agent / 自动化工作流

| 指标 | 数据 |
|------|------|
| **2026年市场规模** | $238.9亿（工作流自动化整体） |
| **CAGR** | 15-20% |
| **商业化进展** | 传统RPA（UiPath等）已盈利，但纯LLM-based Agent尚处早期。Anthropic内部数据显示AI Agent能编写80%代码，但企业级部署仍有限。 |

**判断**: 工作流自动化整体接近边界，但**纯大模型Agent**部分远未达到编程市场一半。处于从传统RPA向LLM Agent过渡阶段。

### 5. 医疗 / 健康 ⭐【最接近候选者】

| 指标 | 数据 |
|------|------|
| **2025年市场规模** | $369.6-393.4亿（AI in Healthcare整体） |
| **2026年预计** | $512-560.1亿 |
| **CAGR** | 35-44% |
| **商业化进展** | 医疗影像AI（如IDx-DR、Viz.ai）已有FDA批准并收费。AI药物发现（如Exscientia、Recursion）有合作收入。微软-IDC研究显示：79%医疗机构已用AI，ROI 14个月，每投$1赚$3.20。 |
| **是否赚钱** | ✅ **部分盈利**（影像诊断、药物发现），但大量初创公司仍烧钱 |
| **vs编程市场** | **约编程市场的51-112%**（已达标！） |

**关键辨析**: AI医疗$51-56B的市场规模**已超过编程市场的一半**（$25-50B）。但需注意：
- 此数字包含**所有AI技术**（传统ML、计算机视觉、NLP等），不只是大模型
- 纯LLM/大模型在医疗中的应用（如病历生成、诊断对话、医学问答）可能只占$5-15B
- 大模型医疗应用面临严格监管（FDA、NMPA），商业化速度慢于编程

**判断**: 若按"AI整体"算，**医疗已达标**。若严格按"大模型"算，**尚未达标但最接近**。是目前最有希望的候选者。

## 四、核心结论

### 问题答案：**截至2026年6月6日，尚未出现明确满足所有条件的场景。但AI医疗/健康是最接近的候选者。**

具体拆解：

1. **若严格按"大模型业务场景"定义**（LLM-based、独立计费、直接收入）：
   - **没有任何场景**达到编程市场的一半（$25-50B）
   - 最接近的是**AI客服**（$19B）和**AI工作流自动化**（$24B），但都差约20-50%

2. **若放宽到"AI整体应用"**（包含传统ML、CV、NLP等）：
   - **AI医疗/健康**（$51-56B）**已达标**
   - 但这是"AI医疗"整体，不是纯"大模型医疗"

3. **商业化维度**（"非烧钱"）：
   - **编程、客服、金融科技**是明确盈利的
   - **医疗**是部分盈利（影像、药物发现有收入，但大量初创公司烧钱）
   - **内容创作、教育、法律**多数仍在烧钱或微利

4. **时间线判断（2026年底前）**：
   - AI医疗若要纯大模型部分达到$25B，需要LLM在诊断、药物发现、病历生成等领域实现大规模商业化，时间非常紧迫
   - AI客服若要达到$25B，需要年增长60%+，可能性低
   - AI工作流自动化若要达到$25B，需要LLM Agent爆发式增长，有一定可能性
   - **最可能的路径**：AI医疗整体继续扩张，或AI Agent+工作流自动化合并成一个更大的"AI生产力"市场

### 最终判断：
**2026年底前出现另一个满足所有条件（大模型、赚钱、规模≥编程一半）的场景概率约为30-40%。若放宽到"AI整体"，则概率升至60-70%（医疗已达标）。**

最值得关注的三条路径：
1. **AI医疗/健康**：规模最大，已达标。需要观察纯LLM部分的独立商业化进展
2. **AI Agent+工作流自动化**：增长最快，如果LLM Agent在2026年H2实现企业级突破，可能达到$25B
3. **AI客服+销售**：商业化最成熟，但天花板较低，需要新业务模式才能翻倍
