# Tombkeeper AI趋势追踪报告

**日期**: 2026-09-06  
**追踪问题**: 除了编程，2026年底前会出现另一个能赚钱（非烧钱）且市场规模至少是编程一半的大模型业务场景吗？

---

## 一、编程市场基准（参照物）

| 指标 | 数据 |
|------|------|
| AI代码工具市场整体规模 | **$7-10B**（2025-2026） |
| Cursor ARR | **$2B**（2026年2月）→ **$4B**（2026年5月） |
| Claude Code ARR | **$2.5B**（2026年初）→ **~$8B**（2026年5月，含Anthropic整体） |

> 关键信号：Cursor从$1B到$2B ARR仅用3个月，是史上最快SaaS增长。Claude Code 8个月内增长6倍。AI编程是当下最明确的盈利场景。

## 二、各候选领域分析

### 1. AI Agent / 自动化工作流

| 指标 | 数据 |
|------|------|
| LLM-powered AI Agents市场 | $2.82B（2025）→ **$4.13B**（2026） |
| AI企业自动化市场 | $12.4B（2025）→ **$13.2B**（2026） |
| 工作流自动化市场 | $23.77B（2025）→ **$26.01B**（2026） |
| Agentic AI企业自动化（纯Agent） | **$410M**（2025）→ $806M（2032） |
| 智能自动化市场 | **$17.0B**（2025） |
| AI自动化市场（广义） | $129.92B（2025）→ **$169.46B**（2026） |
| RPA市场 | $22.58B（2025）→ $27.22B（2026） |

**商业化进展**：
- 88%企业已在至少一个业务功能中使用AI（McKinsey 2025）
- 但仅**12%的CEO**报告AI带来了成本和收入双收益（PwC 2026）
- 56%的企业报告没有可衡量的财务收益
- 40%的Agentic AI项目将在2027年底前被取消（Gartner）
- Agentic AI平均毛利约60%，但规模化部署仍处早期

**判断**：工作流自动化市场$26B已接近阈值，但其中大部分是传统RPA/BPA，非纯大模型驱动。纯Agent市场仅$4B，远未达标。

### 2. 内容创作 / 营销

| 指标 | 数据 |
|------|------|
| AI内容创作市场 | $2.148B（2024）→ 预计$15.38B（2035），CAGR 19.6% |
| 主要玩家 | Jasper、Copy.ai、Midjourney、Stable Diffusion、Sora等 |

**商业化进展**：
- 该领域竞争激烈，产品同质化严重
- 大量免费/低价替代品压缩盈利空间
- 尚未出现$1B+ ARR的独立公司
- 多为烧钱获客模式，留存率存疑

**判断**：市场规模不足，且盈利状况不佳。不满足条件。

### 3. 教育 / 培训

| 指标 | 数据 |
|------|------|
| 自适应学习市场 | $5.49B（2025）→ **$6.48B**（2026） |
| 主要应用 | 个性化学习路径、AI导师、自动评分 |

**商业化进展**：
- B端企业培训有稳定预算，但付费意愿有限
- C端消费者付费转化率低
- 尚未出现规模化盈利的AI教育公司

**判断**：市场规模远低于阈值。不满足条件。

### 4. 法律 / 合规

| 指标 | 数据 |
|------|------|
| 全球法律科技市场 | **$28B**（2022年估值） |
| 主要应用 | 合同审查、法律研究、eDiscovery、合规自动化 |
| JPMorgan COiN平台 | 每年节省36万法律工作小时 |

**商业化进展**：
- 法律服务客单价高，但销售周期长
- 主要被传统法律科技公司占据，AI大模型渗透率低
- 合规自动化有明确ROI，但市场规模增长缓慢

**判断**：整体市场$28B，但AI大模型渗透率极低。不满足条件。

### 5. 医疗 / 健康

| 指标 | 数据 |
|------|------|
| 生成式AI医疗市场 | $1.842B（2025）→ **$21.64B**（2034），CAGR 31.4% |
| 主要应用 | 医学影像诊断、药物研发、临床文档、个性化治疗 |

**商业化进展**：

- 多数公司仍处于烧钱研发阶段

**判断**：2026年仅约$2-3B，远低于阈值。不满足条件。

### 6. 金融 / 分析 ⭐最接近候选

| 指标 | 数据 |
|------|------|
| AI in Fintech市场 | $36.96B（2025）→ **$45.53B**（2026） |
| 全球金融科技市场（含AI） | $262.55B（2025）→ **$328.66B**（2026） |
| 机器人顾问市场 | $14.08B（2026）→ $102.03B（2034） |
| AI反欺诈节省 | 42%发卡机构两年内节省>$500万 |
| JPMorgan AI节省 | **近$15亿**（欺诈检测+交易+信贷决策） |
| 算法交易系统 | AI驱动系统管理>70%股票交易 |

**商业化进展**：
- **最成熟的AI商业化领域之一**
- 反欺诈有明确ROI：AI阻止92%欺诈交易（ABA Banking Journal 2026）
- 信贷审批从48小时缩短至8分钟
- Bank of America Erica：30亿+对话，70-85%常规查询无需人工
- 但需注意：$45.53B包含大量传统AI（规则引擎、ML），非纯大模型

**判断**：广义AI金融科技$45.53B已超过阈值。但纯大模型业务占比不明。若算广义AI金融，**已达标**；若严格限定大模型原生业务，可能仅$5-10B。

### 7. 客户服务

| 指标 | 数据 |
|------|------|
| 企业聊天机器人市场 | 从实验性部署转向生产级规模 |
| 主要趋势 | Gartner预测聊天机器人将成为主要客户服务渠道 |

- 大模型驱动的客服比传统NLP客服成本高（API调用费）
- 企业从"试点"转向"生产"，但纯大模型占比仍低

**判断**：缺乏独立市场规模数据。不满足条件。

## 四、核心判断

### 结论：截至2026年9月6日，尚未出现明确满足"大模型原生+赚钱+≥编程一半"条件的业务场景。

**但有一个领域接近：AI金融科技**

- 广义AI金融科技市场$45.53B（2026）已超过编程市场的一半
- 有明确盈利案例（JPMorgan $15亿节省、反欺诈92%拦截率）
- **关键问题**：$45.53B中纯大模型（LLM-native）业务占比不明
  - 大量是传统ML、规则引擎、统计模型
  - 纯LLM驱动的金融分析/交易/顾问可能仅占10-20%（约$5-9B）

### 需要继续追踪的信号：

1. **AI Agent市场**：若2026年底前Agentic AI从$4B增长至$15B+，可能达标
2. **金融大模型**：若出现LLM-native金融产品的明确收入拆分
3. **企业自动化**：工作流自动化$26B（2026），若大模型渗透率快速提升可能达标
4. **AI编程市场本身**：若继续膨胀至$100B+，阈值相应提高
