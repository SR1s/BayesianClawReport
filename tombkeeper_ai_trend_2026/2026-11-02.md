# AI市场机会追踪：tombkeeper 问题

**追踪问题**：除了编程，2026年底前会出现另一个能赚钱（非烧钱）且市场规模至少是编程一半的大模型业务场景吗？

**追踪日期**：2026-11-02
**基准设定**：编程应用层实际收入 2026 年约 $8-12B（狭义 $7-10B，Claude Code $2.5B+ ARR / Copilot 数百万付费席位）；若计入模型层 API 中编程消耗，口径上移至 $35-60B；用户原始 TAM 口径 $50-100B，一半门槛 $25-50B

---

## 一、过去24小时重要信号（2026-10-31/11-02）

1. **Anthropic S-1 财务细节进一步披露——非编程收入基数被确认巨大**
   - 2026 上半年营收 **$162.86 亿**（+1304% YoY）；API 按量计费收入 **$131 亿（占 80%）**，订阅 $32 亿（占 20%）
   - 账面净亏损 $807.48 亿，但其中 ~$724 亿为可转债/SAFE 公允价值变动的非现金会计项；**经营亏损仅 $6.93 亿**（同比收窄 68%），2026 Q2 单季经营利润 **+$9.74 亿**（首次转正）
   - Q3 营收 ~$168 亿（环比 +45%），年化运行率 **~$65-68B**；净收入留存率 **900%**
   - 客户结构：年化收入 >$10 万客户 1.19 万家（一年前 950 家）；>$100 万客户 1,900+ 家；无单一客户占比 >10%
   - Claude Code ARR $2.5B+（占企业级编码 Agent 市场 54%）
   - **含义**：Anthropic 总盘子年化 $65B+，即使 Claude Code 全部计入，**非编程 API 收入年化已达 $50B+ 量级**——这是"编程之外大模型业务已大规模真实付费"的最硬证据。企业用 Token 计费的 Agentic 工作流（办公自动化、分析、客服、合规等）已在产生可衡量收入
2. **全球科技股 10 月最后一周剧烈调整——盈利验证压力上升**
   - 10/29 谷歌三季报后单日 **-13%**（Q3 自由现金流转负至 -$90.65 亿）；10/30 英特尔单日 **-29%**（40 年来最大跌幅）
   - Anthropic IPO 递交（10/26，代码 ANT，估值目标 $1.5-2T）一度提振情绪，但财报季"AI 盈利兑现忧虑"主导市场
   - **含义**：资本市场对"讲故事"的容忍度快速下降，"单位经济模型先跑通"成为定价主线。对本追踪问题影响双向：烧钱场景被加速出清，已验证赚钱场景的稀缺性溢价上升
3. **Apple 智能官宣登陆中国（10/31 新闻稿）**
   - 首批功能 11/4 起随 iOS 开发者 Beta 开放测试，12 月 iOS 27.3 正式发布；与阿里合作，Siri/写作工具/视觉智能接入**千问**
   - **含义**：C 端 AI 入口级分发落地中国，写作工具+视觉智能属"内容创作"大类；短期直接收入贡献有限，但验证了内容创作场景的设备级渗透
4. **中国营销 AI 商业化硬数据：迈富时 H1 2026 盈喜**
   - AI 应用业务收入 **¥10.68-11.80 亿（+112%-134%）**，占总收入 57.5%；增长来自场景 Token 计费在 GEO、外贸、经营分析等 Agent 产品渗透
   - **含义**：营销/内容 Agent 在中国 B 端已出现"收入翻倍 + 占比过半"的上市公司级证据，内容创作赛道的"赚钱"属性再获验证
5. **AI 办公 Agent 中国市场数据更新（IDC）**
   - 2025 年 ¥212 亿 → 2026 年 **¥449 亿**（~$6.3B），2029 年预计 ¥3,320 亿（CAGR 94.8%）；企业采纳率 40.3%（2024 年底 17.3%），100-499 人中型企业付费意愿 58.5%
   - **含义**："办公自动化"作为 Agent 第一大落地场景，中国侧规模已达编程应用层的 ~50-80%（全球口径），是最接近"编程之外第二个超级场景"的候选之一

## 二、各候选领域数据盘点（2026-11-02 更新）

### 1. AI Agent / 自动化工作流 —— **⭐ 今日上调：从"形态"修正为"可归因场景"**
- **市场规模**：全球 AI Agent 2026 年 **$28-28.6B**（狭义，同比 +350%）；Gartner+IDC 复合宽口径 **$117.8B**；中国企业级 Agent ¥449 亿（办公）+ 全口径预测破 2 万亿元（最激进口径，存疑）
- **收入与盈利证据**：
  - **Anthropic 企业 API 年化 $50B+（非编程）**——含大量 Agentic 工作流调用（11/01 已记录，今日 S-1 细节强化）
  - 头部 Agent ARR（11/01 基线）：Cognition ~$10 亿、Manus ~$5 亿、Glean $3 亿、Harvey $4 亿、Sierra $2 亿
  - Salesforce Agentforce ARR $8 亿（+169%）；ServiceNow Now Assist ACV $6 亿；迈富时 AI 收入 ¥10.7-11.8 亿（+112-134%）
  - ROI：企业级 Agent 平均 ROI 4.7 倍；客服场景单次解决 $0.62 vs 人工 $7.40
- **风险面**：Gartner——2027 年 40%+ Agentic AI 项目或因定价/价值不明/风控被暂停；MIT——95% 企业尚未实现 AI 正财务回报；74% 中国企业将成本列为首要顾虑
- **与编程对比**：狭义 $28B ≈ 编程应用层 2.3-3.5 倍；Anthropic 非编程 API 收入年化 $50B+ 已达口径 C（$25-50B）上沿
- **判断**：⚠️→✅ **上调**——关键变化是 Anthropic S-1 证明了"非编程的按量付费 Agentic 工作流"已是数百亿美元级真实收入，而非预测。但仍需注意该收入是跨行业打包口径（办公+客服+分析+合规），无法整体归给单一"场景"

### 2. 内容创作 / 营销 —— **维持头号候选**
- 11/01 基线不变：GenAI 内容创作 $24.08B（2026）；媒体娱乐宽口径 $43.1B；字节大模型业务 ARR $40 亿（Seedance 毛利 60-70%）；Kling 年化 >$300M
- **今日增量**：迈富时营销 AI 收入翻倍（见信号 4）；Apple 智能写作工具入华（设备级入口）
- **判断**：✅✅ 维持——赚钱证据最纯（生成式 AI 为核心驱动力），规模口径 A/B 达标，口径 C 边界-达标

### 3. AI 金融科技 / 分析
- 11/01 基线：$28.59B（最保守）~$45.53B（最宽）；AI robo-advisory AUM $2.1T
- **今日增量**：无重大新数据；金融科技行业采用率 74-81%（美国企业 AI 采用率分行业前二）
- **判断**：✅ 维持宽口径达标；纯 LLM 原生占比仍待拆分

### 4. 客户服务
- 头部：Zendesk AI ~$10 亿、Intercom ~$5 亿、Sierra $2 亿、NICE AI ARR $3.62 亿（+52%）
- 2026 全球 AI 客服市场 ~$52.7B（宽口径）；AI 原生软件 $15.1B
- **判断**：✅✅ 维持——赚钱已验证（客服是 ROI 最清晰的 Agent 场景），AI 原生规模约为编程应用层 1.3-1.9 倍，宽口径超 $50B

### 5. 医疗 / 健康
- 2026 全球医疗 AI **$48.5-56B**（两机构口径：IIM $48.5B / Fortune BI $56.01B，+32-43% YoY）；医学影像 AI 软件 $12B+ 为最大细分
- **判断**：✅ 维持宽口径达标；大模型原生（ambient 文书/患者交互）占比仍低

### 6. 法律 / 合规
- Harvey ARR $4 亿（+290%）、估值 $155 亿；法律 AI 软件 $5.59B
- **判断**：❌ 维持——头部爆发，赛道总量距门槛差一个数量级

### 7. 游戏 / 娱乐
- AI in Media & Entertainment $43.1B（2026）；GenAI in Gaming 狭义 $2.21B
- **判断**：⚠️ 维持——宽口径达标但大模型原生占比低

### 8. 教育 / 培训
- **判断**：❌ 维持——无增量突破

### 关键变量与不确定性

1. **Anthropic IPO 路演启动（最早 11/9 当周）**：S-1 正式版若披露编程 vs 非编程收入拆分，将直接校准口径 B/C 基数。当前推断：Claude Code $2.5B ARR + 编程类 API 消耗 ≈ 总盘子的 15-25%，**非编程占 75-85%**。
2. **"非烧钱"的定义复核**：Anthropic 整体经营亏损仍略大于零（H1 -$6.93 亿），但 Q2 已单季转正且趋势明确；内容创作赛道头部（字节 Seedance、昆仑万维短剧）毛利率 60-70% / 净利率 60%。真正"还在烧钱"的是机器人/具身智能、AI 视频底层模型军备竞赛（Sora 已因此关停）。
3. **跨行业打包问题**：Agent 口径 C 达标的本质是"企业为 Agentic 工作流付费"这一事实成立，但它不是单一垂直场景。若用户问题严格要求"单一业务场景"，则内容创作仍是唯一干净的答案。
4. **市场背景风险**：10 月末科技股剧烈调整（谷歌 -13%、英特尔 -29%）显示 AI 估值进入"盈利验证期"，2026 年底前不排除再有场景因融资断裂被出清。
