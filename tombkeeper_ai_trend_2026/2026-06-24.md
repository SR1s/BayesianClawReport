# Tombkeeper AI 市场机会追踪报告

**追踪问题**: 除了编程，2026年底前会出现另一个能赚钱（非烧钱）且市场规模至少是编程一半的大模型业务场景吗？

**报告日期**: 2026-06-24
**数据来源**: 公开市场研究报告、行业分析、公司披露数据

---

## 一、基准：AI 编程市场

| 指标 | 数值 |
|------|------|
| AI Coding Assistant 市场规模 (2026) | **$12.8B** |
| 开发者使用率 | 85% |
| 主要玩家 | GitHub Copilot (4.7M付费用户), Cursor, Claude Code |
| 用户付费率估算 | ~15-20% |

> **参考基准**: 编程市场总规模约 $50-100B，AI 编程助手占约 $12.8B。本文以 **$12.8B 为直接对比基准**，"一半"即 **$6.4B+**。

## 二、各潜在大模型业务场景分析

### 1. AI Agent / 自动化工作流

| 指标 | 数值 |
|------|------|
| 市场规模 (2025) | $7.92B |
| 市场规模 (2026) | **$11.55B** |
| 预测 (2035) | $294.66B |
| CAGR | 43.57% |
| 商业化状态 | 早期，企业级Agent开始产生实际收入 |

**分析**: 
- 市场规模 $11.55B，已超过编程市场的一半 ($6.4B)
- 但 Agent 赛道目前仍以"烧钱"为主，大量公司依赖融资生存
- 代表性公司: Sierra AI ($100M ARR), Zendesk AI ($200M), Kore.ai ($140M)
- **判断**: 规模达标，但盈利能力存疑（多数公司尚未证明可持续盈利）

### 2. 内容创作 / 营销 (Content Creation & Marketing)

| 指标 | 数值 |
|------|------|
| AI Content Creation (2025) | $2.72B |
| 更广泛的 AI Media & Entertainment (2025) | **$28.2B** |
| AI Media & Entertainment (2026E) | $14.1B - $35.77B |
| Generative AI in Media & Entertainment (2026) | $2.8B |
| CAGR | 25-26% |

**分析**:
- 纯"内容创作AI"细分市场规模较小 ($2.72B)
- 但 AI 赋能的媒体与娱乐整体市场达 $28.2B (2025)，远超编程一半
- 广告营销中 AI 应用增长强劲：美国数字广告达 $225B，其中 AI 优化创意和定向占比持续提升
- 代表性: Adobe Firefly, Canva AI, Synthesia, Midjourney
- **判断**: 整体市场规模远超阈值，且已有明确盈利模式（SaaS订阅、API调用、广告分成）

- **判断**: 规模尚未独立达到阈值，但增长确定性高，预计2026-2027年突破

| CAGR | 39% |

- **判断**: ✅ **规模远超阈值，且商业化成熟，是除编程外最确定的大模型赚钱场景**

## 四、核心结论

### 判断：YES，已经出现多个满足条件的场景

截至2026年6月，**至少有三个大模型业务场景同时满足"规模≥编程一半"和"能赚钱"的条件**：

1. **医疗健康 AI ($36.67B)** — 最确定的大模型赚钱场景
   - AI Scribe（临床文档）是典型大模型应用，付费明确
   - 医学影像、药物发现等子领域已有成熟商业化
   - 医疗刚需属性确保付费意愿

2. **金融科技 AI ($21-28B)** — 规模最大的大模型赚钱场景
   - 反欺诈、风控、合规是强付费场景
   - 数字支付+$12万亿交易量催生巨大AI需求
   - 实际收入而非烧钱，收入倍数6-15x验证商业价值

3. **媒体与娱乐 AI ($28.2B)** — 最广泛的大模型应用场景
   - 内容创作、推荐系统、广告优化全面AI化
   - Adobe、Netflix、TikTok等巨头已深度集成AI
   - 盈利模式多元（SaaS订阅、API、广告分成）

### 特别说明

- **AI Agent ($11.55B)** 规模已达标，但多数公司仍处于"融资烧钱"阶段，尚未证明可持续盈利，属于"高潜力但未完全验证"
- **法律AI** 预计2026年底或2027年初将突破阈值，Harvey AI的快速增长是信号
- **编程市场**本身仍在快速增长（$12.8B → 预计2030年$50B+），所以"一半"的标准也在水涨船高
