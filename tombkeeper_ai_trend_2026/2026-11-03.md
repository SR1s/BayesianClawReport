# AI市场机会追踪：tombkeeper 问题

**追踪问题**：除了编程，2026年底前会出现另一个能赚钱（非烧钱）且市场规模至少是编程一半的大模型业务场景吗？

**追踪日期**：2026-11-03
**基准设定**：编程应用层实际收入 2026 年约 $8-12B（狭义 $7-10B，Claude Code $2.5B+ ARR / Copilot 数百万付费席位）；若计入模型层 API 中编程消耗，口径上移至 $35-60B；用户原始 TAM 口径 $50-100B，一半门槛 $25-50B

---

## 一、过去24-48小时重要信号（2026-11-01/11-03）

1. **Harvey 法律 AI 确认 $400M ARR，估值 $155 亿——垂直 AI 龙头持续爆发但总量仍小**
   - Harvey 2026 年 9 月完成 $550M 融资（Greenoaks 领投），估值 $155 亿；ARR 从 2026 年 1 月的 $190M 增长至 **$400M+（+290% YoY）**，客户 3,000+ 家，覆盖 80% Am Law 100 律所
   - 使用token量从月均 1T 暴增至 **12T**（+1100%），反映法律 Agent 深度嵌入工作流
   - 2026 年连续收购 4 家公司（含 Guardrails AI），并已将部分 base model 从 GPT 切换至开源模型（8 月报道）
   - **含义**：法律 AI 是垂直领域收入增速最快的赛道之一，但 $400M ARR 距离编程一半门槛（$25-50B）仍差约两个数量级。**赛道"赚钱"已验证，"规模"尚未达标**

2. **企业级 Agentic AI 支出确认 $201.9B——Gartner 口径交叉验证**
   - Gartner 2026 年 8 月数据：嵌入企业软件的 Agentic AI 能力支出 **$201.9B（+141% YoY）**；纯 Agent 平台市场 $10.8B（+44-46%）
   - 2025 年初 <5% 的企业应用包含任务型 AI Agent → 2026 年底预计 **40%**
   - 但 Gartner 同时预警：40%+ Agentic AI 项目到 2027 年可能因 ROI 不明确被取消
   - **含义**：与 11/02 Anthropic S-1 披露的"非编程 API 收入年化 $50B+"互相印证——企业 Agentic 工作流支出已达数千亿美元级（宽口径），其中模型 API 按量计费部分 $50B+。烧钱与赚钱并存，纯 Agent 平台层仍处早期投入期

3. **AI 客服市场 2024-2030 增长路径确认：$12B → $48B，年复合增长率 25.8%**
   - MarketsandMarkets 数据：AI 客服市场 $12.06B（2024）→ **$47.82B（2030E）**
   - 2026 年最新运营数据：客服负责人 AI 支出 **+38%**，而整体客服预算仅 +2%；AI 首次响应中位数 7 秒（人工 11 分钟）
   - Deutsche Telekom 美国业务 40% 客户触点已由 AI Agent 处理
   - **含义**：客服是 ROI 最清晰的 Agent 场景（按次计费、替代人力），但 2024 年 $12B 基数意味着 2026 年约 $18-19B，尚未达到编程一半门槛

4. **英矽智能（Insilico Medicine）2026 H1 营收过亿美元——AI 制药商业化拐点信号**
   - AI 驱动药物发现公司英矽智能 2026 上半年营收超 **$1 亿**，含 SK 生物制药 $25 亿合作（含首付款和里程碑）及武田制药近 $6 亿合作
   - 科大讯飞智慧医疗收入 **+58.56%**；OpenEvidence（医疗 AI 临床决策）2025 ARR 超 **$1 亿**
   - **含义**：AI 医疗正从"工具收费"转向"成果分成/里程碑付款"模式，单笔合作金额已达 $25 亿级。但现阶段收入仍以合作首付款为主，可持续性收入占比待验证

5. **全球 AI 支出全景确认：2026 年 $2.53-2.6T，软件+服务超 $1T**
   - Gartner 2026 年 5 月修订：AI 基础设施 $1.43T + AI 软件 $453B + AI 服务 $586B + AI 模型 $33B + AI 安全 $51B = **$2.6T（+47% YoY）**
   - Sequoia：编程/ChatGPT 类应用 2026 年将达 **$10B+ 收入各**；一打法家 $100M+ ARR 的公司超过一打
   - **含义**：AI 支出正从基础设施向应用/服务迁移，2026 年是"应用变现年"。应用层 $453B 中，大模型原生应用占比快速上升

## 二、各候选领域数据盘点（2026-11-03 更新）

### 1. AI Agent / 自动化工作流 —— **⭐ 连续第二日最强信号**
- **市场规模**：狭义（纯 Agent 平台）$10.8-28B；宽口径（嵌入企业软件）**$201.9B**；Anthropic 非编程 API 年化 **$50B+**；中国企业级 Agent ¥449 亿（办公）
- **收入与盈利证据**：
  - Anthropic S-1 确认：非编程 API 收入年化 $50B+，经营亏损收窄 68%，Q2 单季经营利润首次转正
  - Salesforce Agentforce ARR $8 亿（+169%）；迈富时 AI 收入 ¥10.7-11.8 亿（+112-134%）
  - 头部 Agent ARR：Cognition ~$10 亿、Manus ~$5 亿、Glean $3 亿、Harvey $4 亿、Sierra $2 亿
- **风险面**：Gartner——40%+ Agentic AI 项目或被取消；MIT——95% 企业尚未实现 AI 正财务回报；"Agent washing"泛滥
- **与编程对比**：Anthropic 非编程 API $50B+ 已达口径 C（$25-50B）上沿
- **判断**：✅✅ **维持达标**——S-1 + Gartner 双源验证。跨行业打包归因问题仍是唯一保留项

### 2. 内容创作 / 营销 —— **维持头号垂直候选**
- 基线：GenAI 内容创作 $24.08B（2026）；字节大模型 ARR $40 亿（Seedance 毛利 60-70%）；迈富时 AI 收入占比 57.5%
- **今日增量**：无重大新数据；Apple 智能写作工具 11/4 起在华 Beta 测试
- **判断**：✅✅ 维持——赚钱证据最纯，口径 A/B 达标，口径 C 边界-达标

### 3. AI 金融科技 / 分析
- 基线：$28.59-45.53B（宽口径）；AI robo-advisory AUM $2.1T
- **今日增量**：无重大新数据；金融科技 AI 采用率 74-81%（美国前二）
- **判断**：✅ 维持——宽口径达标；纯 LLM 原生占比仍待拆分

### 4. AI 客户服务
- 市场规模：$12.06B（2024）→ $47.82B（2030E）；2026 年估 $18-19B；AI 原生软件 $15.1B
- 头部：Zendesk AI ~$10 亿、Intercom ~$5 亿、Sierra $2 亿（$158 亿估值）、Decagon ~$1 亿（$15 亿估值）
- **今日增量**：客服负责人 AI 支出 +38% vs 整体预算 +2%（Gartner）；AI 首次响应 7 秒 vs 人工 11 分钟；Deutsche Telekom 40% 触点 AI 处理
- **判断**：✅ 维持——赚钱已验证（按次计费模式成熟），但 2026 年规模 ~$18-19B，距口径 C 门槛（$25B）尚有差距；2030 年将大幅超越

### 5. 医疗 / 健康
- 基线：$48.5-56B（2026 宽口径）；医学影像 AI 软件 $12B+
- **今日增量**：英矽智能 H1 2026 营收 $1 亿+（含 $25 亿 SK 合作、$6 亿武田合作）；OpenEvidence ARR $1 亿+；科大讯飞智慧医疗 +58.56%
- **判断**：✅ 维持宽口径达标；大模型原生（ambient 文书/临床决策）占比仍低，但"成果分成"模式打开长期天花板

### 6. 法律 / 合规
- 头部：Harvey ARR $400M（+290%）、估值 $155 亿、3,000+ 客户、80% Am Law 100；法律 AI 软件总量 ~$5.59B
- **今日增量**：Harvey token 使用量从 1T/月 → 12T/月（+1100%）；$550M 融资（9 月）；连续收购 4 家公司
- **判断**：❌ 维持——头部爆发性增长（增速超编程工具），但赛道总量距门槛差约一个数量级。若 Harvey 增速保持（$400M→$1B+ 在 2027 上半年），赛道有望 2027 年接近口径 A 门槛

### 7. 游戏 / 娱乐
- AI in Media & Entertainment $43.1B（2026）；GenAI in Gaming 狭义 $2.21B
- **判断**：⚠️ 维持——宽口径达标但大模型原生占比低；AI 游戏生成工具（如 Genie 类）尚未形成规模收入

### 8. 教育 / 培训
- **判断**：❌ 维持——无增量突破；头部产品仍以免费/低价为主

## 四、判断

**结论：维持「是，已经出现」，置信度与 11/02 持平（高位稳定）。达标场景维持 5-6 个。**

|---|---|---|---|---|---|---|

| 2 | **AI 内容创作/营销** | $24-43B | Apple 写作工具 11/4 华 Beta | ✅ | ✅ | ⚠️（计入字节 MaaS 则 ✅） |

### 关键变量与不确定性

1. **Anthropic IPO 路演进展**：若本周启动路演，S-1 正式版的编程/非编程拆分将是校准所有口径的最重要单一事件
2. **"赚钱 vs 烧钱"边界**：Anthropic 整体经营亏损收窄但尚未全年转正（H1 -$6.93 亿，Q2 +$9.74 亿）；Agent 领域 Gartner 预警 40% 项目或被取消——Agent 的口径 C 达标部分依赖"企业 API 按量计费"这一确定性收入，但纯 Agent 平台层（$10.8B）仍处投入期
3. **跨行业打包问题**：若严格要求"单一垂直业务场景"，内容创作仍是唯一干净达标的答案。Agent 达标本质上是"企业为 AI 能力付费"这一宏观事实，而非单一可命名场景
4. **法律 AI 观察窗口**：Harvey 增速若保持，2027 上半年 ARR 有望达 $1B+，赛道总量 ~$10B，届时将进入口径 A 达标区——是 2027 年最值得关注的新晋候选
5. **AI 客服时间线**：$12B（2024）→ $48B（2030E），2027-2028 年有望进入口径 C 达标区
