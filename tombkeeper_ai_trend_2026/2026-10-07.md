# AI市场机会追踪 — 2026-10-07

## 追踪问题（tombkeeper）
除了编程，2026年底前会出现另一个**能赚钱（非烧钱）**且**市场规模至少是编程一半**的大模型业务场景吗？

**基准线**：编程市场约 $50–100B → 门槛 = **$25–50B 规模且已盈利/非烧钱**。

---

## 一、过去24小时关键进展（2026-10-06）

- **中国大模型集体进入全球云厂商结算体系（10月6日本日新闻）**：AWS Bedrock 官宣接入智谱 GLM-5.3，按模型调用量收入分成；智谱（2513.HK）当日收盘 715.5 港元（+7.59%），市值 3,423 亿港元，年末 ARR 指引从 $24亿 上调至 **$30亿**。此前 9月30日 Baseten 已宣布企业可在 OpenAI Codex 中直接调用 Kimi K3 与 GLM-5.3，费用计入 OpenAI 采购额度——中国开源模型首次进入 OpenAI 企业付费结算通道。
- **商业化模式拐点信号**：自营 API 模式退潮，"托管 API + 云厂商分成"成为出海主路径（高盛：无需自担推理成本 → 毛利率提升）。大模型基础能力变现的通道在拓宽，但这本身仍属"卖能力"而非独立场景。
- **编程基准线再确认**：Cursor ~$4B ARR（2026年6月初），SpaceX 以 $60B 全股票收购（2026年8月完成）；GitHub Copilot 20M+ 用户；OpenAI Codex 5M+ 周活；付费 AI 代码助手市场 ~$8B 年化（区间 $7–10B）。Anthropic 年化收入 $47B（2026年5月，5个月增长5倍），已机密递交 IPO 申请。
- **Menlo Ventures 企业支出大盘**：2025年企业在 GenAI 上支出 $37B，其中 $19B 流向应用层；10+ 个 AI 产品 ARR 超 $10亿，50+ 个超 $1亿。应用层花钱的地方 = 场景收入的镜像。

## 二、各候选领域评估（增量更新）

### 1. AI Agent / 自动化工作流 ⭐最接近门槛（维持首选）
| 指标 | 数据 |
|---|---|
| 第三方市场口径 | 2025年 $7.6B → 2026年 $10.9B → 2033年 $182.9B（CAGR 49.6%，Grand View） |
| 头部可验证收入 | Salesforce Agentforce+Data360 ~$2.9–3.4B ARR（+200% YoY，Q1 FY27 单季 $1.2B）；ServiceNow AI 指引近 $1.5B；Sierra $200M ARR（一年翻倍，$15.8B 估值）；Zendesk AI $200M→目标$500M |
| 标志性事件 | Salesforce 以 $3.6B 收购 Intercom Fin（2026年6月）；Sierra E轮 $950M |
| 盈利证据 | Salesforce/ServiceNow 整体盈利且 AI 线推动再加速；Agent 产品按"解决量/工作量"计价（Fin $0.99/解决，76% 解决率），单元经济已验证为正 |

**判断**：赚钱✅。规模按头部公司 AI/Agent 收入合计 $8–10B + 模型厂商企业 Agentic API 收入（Anthropic $47B 年化主体为企业/Agent 负载）推算，实际支出量级可达 $25B 量级 ✅（口径）；严格第三方市场口径 $10.9B ⚠️ 未达标。增速 200%+ 仍为各领域最快。

### 2. 客户服务 AI（今日新增硬数据，合并入 Agent 大类独立观察）
- AI 客服市场第三方口径：**2026年 $15.12B → 2030年 $47.82B（CAGR 25.8%）**；66% 组织已使用 AI 服务代理（2026）。
- 头部：Salesforce Agentforce $2.9B ARR；Sierra $200M；Zendesk AI ARR $200M（2025底）→ $500M 目标（2026）；Intercom Fin 76% 解决率、$0.99/解决、12,000+ 客户。
- 企业客户侧 ROI 实证：Lloyds 银行 AI 年价值 £100M（2× 于 2025）。

**判断**：赚钱✅（被公认为当前 ROI 最高的 AI 部署领域）。规模 $15.12B（宽口径）≈ 门槛的 30–60%；AI-native 实际收入约 $5–8B。客服是 Agent 大类中商业化最成熟的子场景。

### 3. 医疗/健康 ⚠️名义达标、LLM归因不足
- 第三方口径：AI in Healthcare 2026年 **$45.2–50.7B**（44.9–38.9% CAGR），名义上已超门槛。
- LLM-native 收入开始成规模：**OpenEvidence ~$300M 年化（2026年中），90% 毛利率**（制药广告模式），$12B 估值；Abridge 环境病历 $100M+ ARR（$5.3B 估值，Epic 渠道绑定）；79% 医疗机构 AI 投资回报为正（Microsoft-IDC，平均 14 个月回收）。

**判断**：整体非烧钱✅，但 $45–50B 口径含大量影像 AI/信息化/药研，大模型直接归因收入估计 <$10B。LLM-native 医疗正在从"故事"变成"生意"，2027 年值得重估。

### 4. 法律/合规（收入上修，规模仍差一个数量级）
- **Harvey ~$350M ARR**（创始人对 The Times 确认，2026年9月；Sacra 估 8月已破 $400M），较 2025 年底 $195M 增长约 80%+，200,000+ 律师用户；Legora ~$150M；EvenUp ~$100M；AI-native 法律前五合计 ~$700M–1B。
- 单元经济为所有垂直中最佳之一（高客单、强留存、NRR 120%+），但全行业 AI 收入对应 $350B/年 计费工作市场仍 <0.3%。

**判断**：方向验证完成，规模差距一个数量级以上。不达标（2027 年前无望）。

### 5. 内容创作/营销
- AI 视频生成市场 2026年 **$847M–946M**（→2034年 $3.35B，CAGR ~19%）；反面教材：Sora 关停——$15M/天 推理成本 vs $2.1M 终身收入（2026年3–4月）。
- 正面信号：可灵 ARR ~$5亿（2026年3月，用户破 1 亿）；ElevenLabs $600M ARR（语音）；Midjourney $500–600M（bootstrap、无融资、盈利）；Synthesia $150M+。
- 中国 AI 短剧产值 2026年 ~¥240亿（~$33B），但制作端大量参与者仍烧钱。

**判断**：头部开始盈利✅，市场整体规模 <$1.5B，远未达标。中国短剧产值口径大但盈利不普遍。

### 6. 教育/培训（新增：盈利模型确认，规模小）
- Duolingo FY2025 收入 **$1.037B（+38.6%）**，Q1 2026 收入 $292M、毛利率 73%、调整后 EBITDA 利润率 28.6%、账上现金 $1.1B 无负债——AI 功能在降低内容生产成本并扩张毛利。
- 但市值从 $21.7B 跌至 $5.7B（2026年4月）：增速指引降至 15–18% 引发杀估值。AI 教育科技市场 $9.15B（2025，宽口径）。

**判断**：赚钱✅（教育是最确定的盈利垂直之一），但 AI 归因收入约 $1–2B，远未达标。

### 7. 金融/分析
- Perplexity（AI 答案/Agent）$450M+ ARR（2026年3月）；金融 AI 深嵌银行 IT 盘子（Lloyds £100M/年 价值），独立口径难拆。
- **判断**：赚钱✅，独立规模 $5–10B 估算，暂不达标。

### 8. 游戏/娱乐
- AI-native 游戏收入 <$5B，无可验证的大模型归因收入规模。不达标。

## 三、综合判断（2026-10-07）

**问题：2026年底前是否出现"非编程、赚钱、规模≥编程一半（$25-50B）"的大模型场景？**

| 条件 | 状态 |
|---|---|
| 非编程 | ✅ 企业 Agent、客服、医疗、金融均符合 |
| 非烧钱（已盈利） | ✅ Salesforce/ServiceNow/Anthropic 盈利线、客服 ROI 最高、教育 Duolingo 毛利 73%、医疗 ROI 为正、法律单元经济极佳 |
| 规模 ≥ $25-50B | ⚠️ 第三方口径 AI Agent $10.9B / AI客服 $15.12B 均未达标；头部口径（Agent $8–10B + 模型厂商企业 Agentic 收入）推算可达 $25B 量级；医疗名义 $45–50B 但 LLM 归因 <$10B |

**结论：条件性达标（偏肯定），置信度 ~72%（较 10-06 的 70% 微升）**。

- **首选答案维持：AI Agent / 自动化工作流（企业级，含客服子场景）**。它是编程之外唯一同时满足"非编程 ✅、头部已盈利 ✅、规模按头部收入口径达 $25B 量级 ✅"的场景。今日新增的 Sierra 翻倍、Intercom Fin 收购、AWS-智谱分成等信号继续强化该判断。
- **口径之争仍是核心分歧点**：严格第三方市场研究口径（$10.9B）下未达标，按该口径 CAGR ~50% 推算需到 2027 年底–2028 年才实质触线；头部收入推算口径下已触线。
- **医疗**（名义达标、归因不足）与**中国 AI 短剧**（产值达标、盈利不普遍）是两个边缘案例，均不构成干净的"是"。
- 距 2026 年底仅剩 ~85 天，不可能再有全新场景从零长至 $25B+；判断实际是对现有场景收入口径的确认，新信息只会微调置信度，不会翻转结论。

**值得继续观察的信号**：
1. Anthropic IPO 招股书（目标 2026年10月上市）中企业 Agentic 收入占比——若披露 Agentic 负载占 ARR 主体，"头部口径"将获得决定性确认；
2. Salesforce/ServiceNow 下一季 Agent 收入增速是否维持 200%（维持则全年合计破 $8–10B）；
3. 智谱 $30亿 ARR 指引的分成收入落地情况（中国模型商业化出海样本）；
4. OpenEvidence/Abridge 等医疗 LLM-native 收入是否出现 $1B 级玩家；
5. 可灵分拆后独立财报盈利性（内容赛道"非烧钱"标签能否摘掉）。
