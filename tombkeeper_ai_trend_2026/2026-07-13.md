# AI市场机会追踪：tombkeeper问题
## 追踪问题：除了编程，2026年底前会出现另一个能赚钱（非烧钱）且市场规模至少是编程一半的大模型业务场景吗？

**追踪日期**: 2026-07-13  
**数据来源**: 公开行业报告、企业财报、媒体报道  
**分析模型**: 市场规模对比 + 商业化成熟度评估

---

## 一、编程市场基准（对照组）

编程是当前大模型**最成熟、最赚钱**的单一业务场景：

| 指标 | 数据 |
|------|------|
| AI编程助手市场总规模（2026年） | **$12.8B**（约920亿人民币） |
| 预计2032年市场规模 | $30.1B，CAGR 27% |
| Cursor ARR | **$2B**（20亿美元） |
| Claude Code ARR | **$2.5B+**（25亿美元+） |
| GitHub Copilot 付费用户 | 470万 |
| 开发者AI工具渗透率 | **85%** |

> **编程市场基准线**: 直接AI编程工具市场约 **$50-100B**（含企业级效率提升的间接价值）。一半是 **$25-50B**（约1800-3600亿人民币）。

## 二、各潜在领域分析

### 1. AI Agent / 自动化工作流 ⭐最接近候选

**市场规模**:
- 全球AI Agent市场2026年达 **$28.6B**（约2060亿人民币）
- 预计2030年达$159B，CAGR 53.6%
- 开源本地部署细分：2026年$5.1B

**商业化进展（实际收入）**:
| 产品/公司 | ARR/收入 | 状态 |
|-----------|----------|------|
| Salesforce Agentforce | **$800M** | 大企业产品线，增长169% |
| ServiceNow Now Assist | **$600M+** ACV | 大企业产品线 |
| 阿里云AI（单季度） | ~**90亿人民币** | 云厂商AI收入 |
| Sierra（客服Agent） | 估值$4.5B | **仍在烧钱**，outcome-based收费 |
| Decagon（企业客服） | 估值$1.5B | 高估值，盈利性不明 |

**判断**: AI Agent整体市场规模（$28.6B）已接近编程市场的一半。但扣除其中**编程相关Agent**（Cursor $2B + Claude Code $2.5B + 其他编程工具~$5B = ~$10B）后，非编程Agent剩余约 **$18B**。部分头部公司仍在烧钱，大企业的Agent产品线（Salesforce、ServiceNow）是赚钱的。

**结论**: 市场规模接近门槛，但"非烧钱"属性存疑。⚠️ **部分满足**

---

### 2. 内容创作 / 营销

**市场规模**:
- 中国企业级AI内容生产市场：**突破千亿人民币**（~$140B？需区分"AI内容生产"与"内容生产中的AI部分"）
- 全球AIGC（AI生成内容）市场2026年：**$2.74B**（约20亿人民币）——注意这是纯AIGC工具市场
- 全球内容营销市场2026年：$655.1B（但AI占比很小）
- 中国AI营销SaaS/Agent市场2026年：**636亿元**（约$88亿），2030年将突破1700亿元
- 全球数字内容创作市场2026年：$425.3B（含非AI部分）

**商业化进展**:
| 产品/公司 | 收入数据 | 状态 |
|-----------|----------|------|
| 快手可灵AI | 营收超**1.5亿元** | 已盈利，B端API+C端订阅 |
| 蓝色光标AI业务 | 预计全年**30-50亿元** | AI驱动收入增长 |
| AI视频营销项目 | 平均ROI **1:5.7** | 效果可量化 |
| 海外AI短剧漫剧 | 2026年预计**$650M** | 高速增长 |

**判断**: 纯AIGC工具市场（$2.74B）远小于编程市场。但**AI营销SaaS/Agent**中国市场就达636亿元（~$88亿），全球可能更大。若将AI内容创作、AI视频、AI营销等合并，总市场可能接近或超过编程市场的一半。但"非烧钱"验证不足，多数公司仍在投入期。

**结论**: 市场潜力大，但纯AI收入规模不够明确。⚠️ **部分满足**

### 3. 医疗 / 健康

**市场规模**:
- 医疗大模型行业进入规模化落地阶段
- 国家医保局将**12项AI辅助诊断**纳入全国医保乙类目录
- 江苏超90%三级公立医院已开展AI应用
- 全球AI制药：170余条管线进入临床

**商业化进展**:
- 百川智能Baichuan-M4医疗大模型多项评测登顶
- 京东健康京东卓医大模型：门诊AI服务累计超**910万人次**
- 医疗AI公司收入规模多在**数亿人民币**级别

**判断**: 商业化通道已打开（医保覆盖），但收入规模与编程市场差距巨大。头部公司年收入约**10-50亿人民币**级别，远不及编程市场的1/10。

**结论**: 前景好，但规模不够。❌ **不满足**

### 4. 法律 / 合规

**市场规模**:
- Harvey AI（法律Agent）：估值**$3B**
- EvenUp（人身伤害法律Agent）：估值$1B，处理超3万件
- Klarity（合约审阅）：C轮$7000万

**商业化进展**:
- 法律Agent采用outcome-based收费，客单价高
- 但整体市场规模小，头部公司估值高但收入绝对值有限

**判断**: 高度垂直，客单价高，但**整体市场规模小**（估计全球< $5B）。

**结论**: 细分赛道，规模不够。❌ **不满足**

### 5. 金融 / 分析

**市场规模**:
- 金融行业AI投资回报率最高
- 徽商银行私有化大模型平台落地**163个场景**
- 广发银行落地大模型应用场景**158个**
- 反诈领域2025年全年拦截风险交易**97万笔**

**商业化进展**:
- 多为银行/金融机构**内部使用**，不直接产生外部市场收入
- 用友金融推出"任务交付型"数据分析报告智能体

**判断**: 金融是大模型落地最快的行业之一，但主要是**企业自用**，独立商业化市场规模难以估算，且多数为成本节约型（替代人力），非直接创收。

**结论**: 落地快，但独立市场规模不明确。❌ **不满足**

### 6. 教育 / 培训

**市场规模**:
- 河南省实验中学大模型培育**24个专项智能体**
- 企鹅教师助手上线国家智慧教育公共服务平台
- 猿力科技以前沿AI能力释放教师创造力

**商业化进展**:
- 多为**G端/B端试点**，C端付费意愿弱
- 收入规模远小于编程市场

**判断**: 规模化商业化尚未形成。

**结论**: 早期阶段。❌ **不满足**

### 7. 客户服务

**判断**: 垂直Agent的一个子集，规模不够独立成"大场景"。

**结论**: 细分赛道。❌ **不满足**

## 四、核心结论

### 📊 判断：**截至2026年7月，尚未明确出现满足所有条件的非编程大模型业务场景**

**详细分析**:

1. **AI Agent/自动化工作流是最接近的候选者**
   - 全球市场规模$28.6B，若扣除编程相关Agent（约$10B），非编程Agent剩余~$18B
   - 这已接近编程市场（$50-100B）的**20-36%**，接近但未达到一半
   - **核心问题**: 大量Agent公司（如Sierra、Decagon）仍在高投入期，"非烧钱"属性未完全验证

2. **内容创作/营销是第二候选者**
   - 中国AI营销SaaS市场636亿元（~$88亿），但全球纯AI内容工具市场仅$2.74B
   - 若将AI视频、AI文案、AI营销合并，总市场可能接近$10-20B
   - **核心问题**: "AI内容生产市场突破千亿"的数据口径不明确（是内容生产市场整体，还是AI部分？）

3. **时间窗口判断**
   - 2026年被称为"AI Agent商业化元年"
   - Salesforce Agentforce、ServiceNow等大企业产品线已证明盈利
   - 下半年如果非编程Agent市场继续高速增长，**有可能在2026年底前达到条件**

4. **tombkeeper问题的精确回答**
   - 编程市场的一半 = $25-50B
   - 当前最接近的非编程场景 = AI Agent非编程部分（~$18B）+ AI内容营销（~$10-20B）
   - 两者合计可能接近门槛，但**单独一个场景尚未明确达标**

### 🎯 最终结论

**截至2026年7月13日：否。**

除了编程，**尚未出现另一个同时满足以下两个条件的场景**:
1. 能赚钱（非烧钱，有明确盈利证据）
2. 市场规模至少是编程市场的一半（$25-50B）

**AI Agent/自动化工作流**是最有希望的场景，预计如果在2026年下半年保持当前增速，**有可能在2026年底前成为第一个满足条件的非编程大模型业务场景**。
