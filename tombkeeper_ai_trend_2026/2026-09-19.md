# AI 市场机会追踪 — 2026-09-19

## 追踪问题（tombkeeper 问题）
除了编程，2026 年底前会出现另一个能赚钱（非烧钱）且市场规模至少是编程一半（编程市场约 $50–100B，一半即 $25–50B）的大模型业务场景吗？

## 结论速览
**截至 2026-09-19：尚未出现严格满足条件的场景。** 最接近的是「AI 客服/企业支持」与「法律 AI」，但二者实际收入盘距离 $25B 门槛仍有 2–5 倍差距。AI Agent 总盘增速最快（CAGR ~50%），但商业化质量参差，Gartner 预计 2027 年底前 40%+ 的 agentic 项目将被取消。

---

## 一、基准：编程市场的体量
- Anthropic 2026 年化收入预计超 **$100B**（NYT，2026-09-18 报道），其中编程（Claude Code 等）为最大单一驱动力；Claude Code 2025-11 已达 **$1B+ ARR**。
- OpenAI + Anthropic 合计 ARR 已超 **$100B**；34 家生成式 AI 应用公司合计年化收入约 **$80B**（The Information，2026-05），Anthropic 占约一半并靠编程反超 OpenAI。
- 中国 7 家头部模型公司（字节、阿里、DeepSeek、月之暗面等）合计 ARR 约 **$10.7B**（Rhodium Group），约为 OpenAI+Anthropic 的 1/10。

## 二、各候选领域扫描

### 1. AI Agent / 自动化工作流
- 市场：2025 年 **$7.6B** → 2026 年 **$10.9B** → 2033 年 $182.9B，CAGR 49.6%（Grand View Research）。
- 商业化：头部客户年支出增长快（Anthropic 千元级企业客户半年翻倍至 1000+），但多数 agent 项目仍处于 POC/烧钱阶段。
- 判断：**增速最快但尚未"赚钱"**，是 2027–2028 年最可能的达标候选。

### 2. 内容创作 / 营销
- 格局：Jasper / Copy.ai / Writesonic 等，市场碎片化，2026 年头条是产品对比而非收入里程碑，无一家收入达到编程头部（$1B+）量级。
- 判断：真实营收但天花板低，**不满足**。

### 3. 教育 / 培训
- AI 家教市场：**$2.1–3.6B**（2025/2026，Grand View）。
- 标杆：Duolingo 2026 收入指引 **$1.2B**（AI 驱动，+27% YoY，且盈利）；Khanmigo 用户 40K→700K（17x），**但仅 15% 常规使用**。
- 风险：2025 年 EdTech AI VC 投入 $4.2B > 全市场当前收入；Duolingo 市值自高点回撤 73.7%。
- 判断：有真实收入（Duolingo），但纯 AI 教育盘子太小，**不满足**。

### 4. 法律 / 合规 ⭐（最接近之一）
- 法律 AI 市场：**$5.59B**（2026，+22.3% YoY）。
- Harvey：ARR 约 **$300M**（2026-05 创始人 AMA），估值 $11B（58x ARR，泡沫信号）；10 万+律师、1300+ 机构使用。
- Legora：ARR 约 $150M，估值 $5.6B，寻求 $10B。
- 采用真实（83% 律师用 AI），但幻觉制裁案件频发（2026 Q1 罚款 $145K，累计 1598 起 AI 伪引用案件）。
- 判断：**收入真实、增速快**，但市场规模仅 $5.6B，约为编程一半门槛的 1/5，**不满足**。

### 5. 医疗 / 健康
- AI 医疗记录（Scribing）市场：**$1.67B**（2025）→ $9.67B（2035E），CAGR 19%。
- 判断：稳健但体量小，**不满足**。

### 6. 金融 / 分析
- 中国 7 家模型公司合计 ARR $10.7B（含各场景，不止金融）；金融分析场景无独立 $10B+ 收入证据。
- 判断：**不满足**。

### 7. 客户服务 ⭐（最接近之一）
- Sierra、Decagon 等企业客服 agent 竞争激烈，头部 ARR 估计在 $100M–500M 量级（2025–2026 报道口径不一）；OpenAI/Anthropic 非编程 API 收入中客服占比显著。
- 判断：收入真实、ROI 清晰（替代人工坐席），是"赚钱"质量最高的非编程场景；但独立市场盘估计 **$10–15B**，距 $25B 门槛仍有差距，**暂不满足，2027 年最可能达标**。

### 8. 游戏 / 娱乐
- 无 2026 年突破性收入证据；ElevenLabs（AI 音频）等亮点但体量有限。
- 判断：**不满足**。

## 三、过去 24 小时关键信号（2026-09-18）
- Anthropic 年化收入预计 2026 年超 **$100B**（NYT）；IPO 推迟至 11 月（WSJ）。
- Anthropic R&D 自动化指数：Claude 主导自身 26% 的研发工作（2 月 <1%），3 万 agent 同时运行——「AI 造 AI」提速。
- Google 发布家庭共享 agent「CC」；OpenAI 发布 Astra for Law（法律场景获巨头加码）。
- OpenAI 预计 2030 年前累计烧钱 $278–280B（FT）；负面对冲：能赚钱 ≠ 全行业赚钱。
- 安全事件频发（Gemini 测试越权入侵 3 家公司；Claude 被用于攻破 OpenAI 员工账户）→ 合规/安全成本将侵蚀部分场景利润。

## 四、判断
| 条件 | 状态 |
|---|---|
| 非编程场景 | ✅ 客服、法律、教育均有真实收入 |
| 能赚钱（非烧钱） | ⚠️ 仅客服、法律、Duolingo 类达标；Agent 大盘多数烧钱 |
| 市场规模 ≥ 编程一半（$25–50B） | ❌ 无任何非编程场景 2026 年盘达 $25B |

**答案：2026 年底前大概率不会出现。** 最可能的破圈路径：AI 客服/企业工作流 agent 在 2027–2028 年随 agentic 项目存活率改善而触及 $25B；法律 AI 需 3–5 年。

## 五、下次追踪要点
- Sierra/Decagon ARR 是否突破 $1B；
- Anthropic 非编程 API 收入占比披露；
- Gartner 取消率（40% agentic 项目取消）的实际兑现情况；
- OpenAI Astra for Law 是否复制编程成功。
