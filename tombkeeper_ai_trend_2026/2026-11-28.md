# AI 市场机会追踪 — 2026-11-28

## 追踪问题
> 除了编程，2026年底前会出现另一个能赚钱（非烧钱）且市场规模至少是编程一半的大模型业务场景吗？

## 三、综合判断（2026-11-28）

### 判定：**YES ✅（维持第三天）— 内容创作/营销唯一达标；无新场景在本期达到阈值；行业"非烧钱"属性本周获财报级确认**

| 判定维度 | 评估 |
|----------|------|
| 非编程 | ✅ 内容创作/营销与编程独立 |
| 非烧钱 | ✅ **本周升级**：Anthropic 26Q2 单季经营利润转正（+8.4%）、美团 AI 投入伴随集团扭亏、Omdia 确认行业收入 $200B 翻倍 —— 供给侧盈利拐点+需求侧计价化同时发生 |
| 2026年底前出现 | ✅ 已存在（2025 年即达 $21.5B，2026E $28.75B） |
| 规模 ≥ 编程一半 | ✅ $28.75B / $34B = 85%；广义 $47B / $34B = 138% |

### 关键逻辑链（本期更新）

1. **"能赚钱"判定获得本季度最强证据**：Anthropic 单季经营利润转正（+8.4% 利润率、85.5% 毛利率）意味着头部模型厂商已越过经营平衡点；美团扭亏+研发加码 AI 证明应用侧 ROI 可覆盖投入。**"非烧钱"从今天起不再是假设，而是有 GAAP 报表支撑的既成事实。**
2. **内容创作/营销的三重巩固**：卖方千亿美元远期锚（中信证券）+ 上市公司收入实证（微盟 +89.2%）+ 算力订单需求外溢（官方公告点名营销内容生成）。短期无口径翻转风险。
3. **DeepSeek 计价透明化是消费端付费的前奏**：当用户能看到每轮对话的"价格"，订阅/按量付费的心理门槛下降——2027 年 C 端变现弹性值得上调，但本期不改变任何场景的规模判定。
4. **MiniMax 下架 = 消费场景折价因子**：139 万付费用户证明需求真实，但苹果一纸下架即击穿商业化连续性。这强化了"**B2B/专业工作流优先于 C 端娱乐**"的排序，与 Sora 关停教训一致。
5. **编程仍是所有口径下的收入之王**：阿里百炼直言 API 增长"几乎全部由 AI 编程带动"；Menlo $34B 基准未动摇。其他场景的追赶是 2027-2028 年的故事。

## 四、关键不确定性与下步观察点

1. **内容创作口径之争（不变）**：Menlo 企业采购口径下营销 AI 仅 $1.2B。观察 Adobe/Canva/微盟 AI 收入单独披露进度——微盟本期已开了好头。
2. **DeepSeek 付费墙落地时点**：资费展示 → 额度收紧 → 正式收费，若 2027Q1 落地将改变 C 端市场格局与"通用助手"场景规模测算。
3. **MiniMax 事件扩散风险**：若苹果/Google 对 AI 陪伴类应用系统性收紧，消费场景收入预测需下修；同时观察国内监管对"星野"类产品的态度。
4. **Anthropic 年底 ARR $1000 亿目标**：Q4（当前季度）财报将是"编程+Agent 双引擎"故事的关键验证；其中 Cowork（办公自动化 Agent）收入拆分是"第二个达标场景"的最大潜在催化。
5. **Menlo 2027 年报告（2027-11）**：客服能否守住 4.3x 增速冲 $10B+；Agentic 独立口径能否在 Omdia 104% CAGR 支撑下提前达标。
6. **宏观风险**：BIS 出口管制（11.16 规则）+ 黄仁勋事件 + 12 月美联储议息——不改变应用层事实，但影响估值与算力成本。
