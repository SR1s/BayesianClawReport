# AI 市场机会追踪：编程之外的"赚钱场景"判断

**日期**：2026-09-23（Asia/Shanghai 10:22）
**追踪问题**：除了编程，2026年底前会出现另一个能赚钱（非烧钱）且市场规模至少是编程一半的大模型业务场景吗？

---

## 一、编程市场基准（今日更新）

|---|---|---|
| 企业 AI 编程 agent 市场（2026-04 年化） | $9.8–11.0B | Gartner（2026-05-20） |

- 用户设定基准：编程市场约 **$50–100B**，一半 = **$25–50B**。
- 按 AI 编程工具实际收入口径（$10–13B/年），一半约 **$5–6.5B**。判断对口径敏感，双口径并列。

## 二、各领域商业化进展扫描（今日增量）

### 1. 客户服务 ⭐最接近的候选（今日新增关键证据）
- **Salesforce Agentforce：ARR $1.2B，同比 +205%**（FY2027 Q1，截至 2026-04-30）；与 Data 360 合计 ARR ~$3.4B——企业级客服/销售 agent 首次出现十亿美元级真实收入（CSDN 软件行业调查，2026-09-03）。
- **Sierra**：ARR $100M（2025-11）→ $150M（2026-02），7 个季度破 $100M；2026-05 融资 $950M、估值 $15.8B；Fortune 50 中 40%+ 为客户；平台覆盖 95% 美国购物者、50% 美国家庭医疗、70% 金融科技价值链；目标 2026 ARR $500M（AIEII/TechCrunch）。
- 定价已跑通按成果计费：Intercom Fin $0.99/次解决、平均解决率 76%（12,000 客户）；Zendesk 按"已验证解决" $1.2–1.5/次；Sierra 企业合同年 $15–75 万 + 导入费。
- **风险信号**：Sierra 100x 市销率 = 估值驱动 > 利润驱动；Agentforce 高增长背后，市场开始定价"agent 替代席位侵蚀 Salesforce 席位制底座"（股价年内 -33%）。
- 判断：收入真实、增速惊人、单位经济可算；纯玩家盈利未验证。**收入池估计 $4–8B，达编程收入一半的边缘。**

### 2. 企业办公/通用 Agent 工作流（今日最大新增）
- **微软 M365 Copilot 付费席位超 3,000 万**（上一季度约 2,000 万，单季 +50%）；按 $30/席/月估算年化潜力 **~$10B 量级**，且微软整体高盈利（FY2026 Q4 营收 $90B，Azure 年收入破 $1,000 亿，商业剩余履约义务 $6,780 亿同比 +84%）。
- 中国侧：千问办公上线 30 天用户破 3,000 万（一半以上企业用户）；飞书 2026 上半年 ARR 增速达去年同期 2.5 倍、全面"Agent 为一等公民"改造（财新，2026-09-15）。
- 企业 agent 大盘：2026 全球 **$11.55B**（Precedence Research，2025 为 $7.92B）；60% 大企业已有生产级 agent 工作流；80% 企业称 agent 已产生可测 ROI（getpanto, 2026-08）。
- 智谱企业级智能体收入 5,560 万元（+304%，占比仅 5.8%）——中国独立模型厂该业务收入仍小，收入主要沉淀在平台巨头。
- 判断：**"办公 Agent"若算作一个场景，是今日非编程领域收入最大的候选**（Copilot 年化 ~$10B），但盈利记在微软整体账上；独立厂商多数仍在投入期。

### 3. AI Agent / 自动化（通用平台）
- 中国 AI Agent 市场：2025 2.6 万亿元 → 2030 20.1 万亿元（沙利文/头豹，2026-08-05）——TAM 口径，含 B 端九成收入预期，非实际收入。
- 垂直 Agent：35% 专注细分痛点的项目已正向现金流，客单价为通用 SaaS 的 3–5 倍，续费率 85%+（腾讯云开发者社区，2026-06-24）。
- 风险依旧：88% 企业 agent 项目未进生产（IDC/Lenovo）；Gartner 曾预测 40%+ agentic 项目 2027 年底前被取消。
- 判断：长尾在赚钱，平台在烧钱；整体不满足。

### 4. 内容创作 / 营销
- 可灵 AI 年化收入近 **$500M**（2026-03），同比 +300%；Kling 企业客户 30,000+。
- Midjourney ~$500M 年收入、已证盈利；Runway $300M 年化。
- 反面教材延续：Sora 2026-04 关停（推理成本 $15M/日 vs 累计收入 $2.1M）。
- 判断：头部合计 $1.5–2B，**有盈利案例但规模距一半口径尚远**。

### 5. 法律 / 合规
- Harvey ARR $300M（2026-05），估值 $11B；Legora ARR 破 $100M。AI in Legal 市场 2026 $5.59B。
- 判断：真实收入、高客单价，**按编程收入口径已接近一半**；全行业未盈利。维持昨日判断。

### 6. 医疗 / 健康
- 无重大新增盈利证据。中国 AI 医疗影像市场基数小（2022 约 45 亿元），SaaS 占比提升中；AI 药物发现名义市场 $5B+ 但里程碑收入 ≠ 利润。
- 判断：**规模口径边缘、盈利口径不满足**。维持。

### 7. 金融 / 分析、教育、游戏
- 教育 AI tutors 市场 $2.75B（2026），Duolingo 整体 $1.2B 指引且盈利——但规模远不够。
- 金融侧仍为早期小额融资；游戏仅早期项目。
- 判断：**不满足**。

### 8. 自动驾驶 / Robotaxi（边缘相关，大模型为核）
- 今日新增：小马智行深圳车队 2026-02 **单车盈利转正**（日均净收入 338 元、23 单）；Waymo 周付费订单 50 万次、两年规模增十倍、旧金山等市场正毛利（财新，2026-09-21）。
- 但：小马智行、文远知行 2026 Q2 仍各有数亿元经营亏损；车队扩张靠融资输血。
- 判断：**单位经济首次转正值得标记，公司层面仍烧钱**；且"是否算大模型业务场景"存在口径争议（端到端大模型驾驶）。暂不纳入主判断，列为观察项。

## 四、判断结论

**维持双口径框架，结论较昨日微调：**

1. **严格按用户基准（一半 = $25–50B 实际收入）：❌ 尚未出现。**
   非编程场景无一达到 $25B 年收入。最大的三个收入池：办公 Agent（Copilot 年化 ~$10B 量级，计入微软整体盈利）、客服 Agent（$4–8B，头部未盈利）、企业 agent 整体 $11.55B（含上述两者）。距 $25B 门槛仍有 2–3 倍差距，2026 年内（剩 3 个月）翻转概率 **<15%**。

2. **按 AI 编程工具实际收入口径（一半 ≈ $5–6.5B）：⚠️→✅ 边缘转达标。**
   - **客服 Agent 收入池 $4–8B**：Agentforce $1.2B ARR（+205%）+ Sierra（冲 $500M）+ Fin/Zendesk/Ada/Decagon + 中国厂商——**规模上已触及一半线**，Sierra 百倍 P/S 提示"赚钱"仍待验证。
   - **办公 Agent（Copilot 生态）年化 ~$10B**：**规模明确超过编程收入一半，且微软整体盈利**——若认定"办公 Agent"为独立业务场景，则条件满足。
   - 真正同时满足"非烧钱 + 规模"的纯玩家：仍无（盈利者太小，大者未盈利）。

**一句话判断**：截至 2026-09-23，严格口径下答案仍为"**尚未出现**"，但本月数据（Agentforce $1.2B ARR、Copilot 3,000 万席位、Sierra 冲 $500M）使**"企业客服+办公 Agent"组合首次在收入规模上摸到编程市场一半的边缘**；若把微软 Copilot 生态单计为一个场景，宽松口径下可判"已出现"。剩 3 个月，严格口径翻转需该收入池再增 2 倍，可能性低。最确定的赢家画像：靠在位企业软件渠道变现 agent（微软/Salesforce），而非独立 AI 原生公司。
