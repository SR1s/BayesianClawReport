# AI 市场机会追踪 — 2026-11-04

> **追踪问题**：除了编程，2026年底前会出现另一个能赚钱（非烧钱）且市场规模至少是编程一半的大模型业务场景吗？
>
> **判断框架**：沿用 2026-11-03 确立的三口径基准——A：编程应用层实际收入 $8-12B（一半门槛 $4-6B）；B：含模型层 API 编程消耗 $35-60B（一半门槛 $17.5-30B）；C：用户原始 TAM 口径 $50-100B（一半门槛 $25-50B）。两条件须同时满足：**实际收入（非烧钱）** + **规模 ≥ 门槛**。

### 2. 企业生成式 AI 支出跃升

- 企业已设立专门 AI 预算科目，采购框架成熟——Agent/工作流场景"赚钱"属性的底层支撑

### 3. AMD Q4 2026 指引超预期（11/3 财报）

- 意义：基础设施层需求持续强劲（非应用场景，但确认 AI 支出无退潮迹象）

### 5. 资本流向观察：从屏幕到原子

- 2025 年 AI 风投 $211B（占全球 VC ~50%）；2026-Q1 基础模型融资超 2025 全年（Crunchbase）

- OpenAI $110B 轮 @ $7300 亿估值 finalized；xAI $20B
- 垂直 Agent 持续获投：Decagon $250M D 轮（客服运营）、Trase $107M 种子（医疗 Agent）、Assort Health $120M C 轮（患者旅程）

### 6. 编程市场基准上修压力（校准项）

- Claude Code $8B ARR（2026-05，Menlo Ventures 口径 54% 市占）→ 隐含 AI 编程工具总盘 ~$15B

- **处理**：今日不改动三口径门槛（避免中期改标准），标记为下次框架校准时统一上修；门槛上调反而使达标更容易（一半门槛随基准同步上升）

### 关键变量与不确定性

1. **Anthropic IPO 定价**：原定 10 月，截至 11/4 未定价。S-1 正式版的编程/非编程拆分将是最重要的单一校准事件。Q2 盈利数据降低了"烧钱"质疑，但 Ed Zitron 泡沫论（承诺数学问题）仍在发酵
2. **会计口径风险**：Anthropic 总额法 vs OpenAI 净额法；CARR 与 ARR 差距在 AI 初创可达 70%（TechCrunch）。规模数字存在系统性乐观偏差的可能，但即使打折 30%，Agent 场景口径 C 依然达标
3. **"单一垂直场景"约束**：严格要求下内容创作仍是唯一干净答案；Agent 达标本质是"企业为 AI 能力付费"的宏观事实
4. **编程基准上修的双刃剑**：Claude Code $8B → 编程盘子上修 → 门槛同步上移 → 达标场景收窄。下次框架更新时统一处理
5. **OpenAI 对比**：OpenAI 全年确认收入 $35B 但仍亏损（Q2 每 $1 收入亏 $1.22）——若用"公司级盈利"严格定义"非烧钱"，目前只有 Anthropic 一家达标，且仅一个季度
